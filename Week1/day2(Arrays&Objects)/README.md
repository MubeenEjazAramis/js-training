# Week 1 Day 2: Arrays and Objects (Student Grades Report)

Build task for Week 1 Day 2.

## Structure

```
Week1/day2(Arrays&Objects)/
├── grades.js   # Student Grades Report build using functional array methods
└── README.md
```

## Features Implemented

- 10 Student records with subject scores across classes A and B.
- Student average and letter grade calculation (`A`, `B`, `C`, `D`, `F`).
- Top 3 students ranking using `.sort()` and `.slice()`.
- Class average calculations for Class A and Class B.
- Grade distribution counting across all grades.
- Biggest subject gap detection using `Math.max()` and `Math.min()`.
- Pure functional implementation: no `for` or `while` loops, all functions under 10 lines.

## How to Run

```bash
node grades.js
```
