# Week 1 Day 3: Scope, Closures, this and Modules

Build task for Week 1 Day 3: Utility Library.

## Structure

```
Week1/day3(Scope&Closures)/
├── README.md
└── utils/
    ├── package.json   # Configured with "type": "module"
    ├── string.js      # capitalize, slugify, truncate
    ├── array.js       # chunk, unique, groupBy
```

## How to Run

Run with Node.js:

```bash
cd "Week1/day3(Scope&Closures)/utils"
node main.js
```
