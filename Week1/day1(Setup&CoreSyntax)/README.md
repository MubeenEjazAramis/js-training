Practice problems and build task for Week 1 Day 1.


## How to Run

### Practice Tasks
Run any practice file using Node.js:
```bash
node practice/p01.js
node practice/p02.js
# ... through p15.js
```

### Number Guessing Game Build
Run the game in terminal:
```bash
node guessing-game/game.js
```
