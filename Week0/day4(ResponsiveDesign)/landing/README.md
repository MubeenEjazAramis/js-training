# Day 4: Responsive Landing Page

Responsive version of the TaskFlow landing page built with pure HTML and CSS.

## Live Demo
- [Live on GitHub Pages](https://mubeenejazaramis.github.io/js-training/Week0/day4(ResponsiveDesign)/)

## Checklist
- [x] Mobile-first: base styles for small screens, media queries at 768px and 1024px
- [x] Navigation menu collapses on mobile using CSS checkbox
- [x] Fluid headings with clamp() and responsive images (max-width: 100%)
- [x] Dark mode with prefers-color-scheme swapping custom properties
- [x] Hover transitions on buttons and cards
- [x] Tested at 375px, 768px and 1440px with no horizontal scroll
