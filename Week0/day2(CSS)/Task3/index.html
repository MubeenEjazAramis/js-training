Box Model: content-box vs border-box

I gave both boxes the exact same CSS values:

  • width: 200px;
  • padding: 20px;
  • border: 5px solid;
  • margin: 10px;

Box A: Default Box (content-box)

Content Area

Actual size on screen: 250px

Calculation: 200px (width) + 40px (padding) + 10px (border) = 250px.


Box B: Better Box (border-box)

Content Area

Actual size on screen: 200px

Calculation: Total size stays 200px. The inside text area shrinks to 150px to adjust the padding and border inside it.
