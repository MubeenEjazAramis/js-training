CSS Variables (Custom Properties)

Testing how to use variables so I don't have to write the same colors again and again.

The Magic Card

The border, background, and button colors on this card are all coming from variables.

If I change the `--main-color` in CSS just once, the border and the button will automatically change their colors together!


Variables I created in CSS:

  • Colors: --main-color, --bg-color
  • Spaces: --space-small, --space-big
