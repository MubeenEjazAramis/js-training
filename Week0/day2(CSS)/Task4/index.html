Testing CSS Units: px, em, rem, %

Note: By default, the main HTML root size is 16px.

1. Normal Parent (Font size: 16px)

px: 24px

em: 1.5em (1.5 x 16 = 24px)

rem: 1.5rem (1.5 x 16 = 24px)

%: 150% (150% of 16 = 24px)

Result: They all look exactly the same size here.

2. Big Parent (Font size: 24px)

px: 24px (Stays the same)

em: 1.5em (It grew! 1.5 x 24 = 36px)

rem: 1.5rem (Still 24px. It ignores the parent)

%: 150% (It grew too! 150% of 24 = 36px)

3. The Nesting Problem (em vs rem)

Using 'em' (Bad idea)

Outer Box (1.2em)
Inside Box (It multiplies and gets bigger)
Deep Inside (It gets huge!)

Using 'rem' (Good idea)

Outer Box (1.2rem)
Inside Box (Stays exactly the same)
Deep Inside (Still the same, no multiplying!)

4. Root Font Size Test (html font-size)

By default, root (html) font size is 16px. If we change root font size:

px: 24px - Fixed size (Does NOT change when root font-size changes)

rem: 1.5rem - Relative to root (Becomes 30px if root is changed to 20px)
