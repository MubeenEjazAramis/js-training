Margin Collapse (Weird CSS Behavior)

Testing why top and bottom margins don't add up properly.

1. Top and Bottom Margins (The bigger one wins)

Box 1 (margin-bottom: 40px)
Box 2 (margin-top: 25px)

Wait! 40px + 25px should be a 65px gap, right? But the gap is only 40px on the screen. The 40px margin ate the 25px margin!



2. Left and Right Margins (These are normal)

Left Box (margin-right: 20px) Right Box (margin-left: 20px)

Total gap here is 40px (20+20). So horizontal margins do NOT collapse. Good to know!
